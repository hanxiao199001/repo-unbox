# 中文排版要求

**这一份是原版没有的。** 原版的排版参数全部是为拉丁字母调的，中文正文套上去会挤、会散、
标点会飘。下面每一条都是硬要求，不是建议。

## 一、正文行高 1.8

中文是方块字，没有 x-height 和上下伸部形成的天然行间空隙，拉丁文排版常用的 1.5–1.6
用在中文上会显得拥挤。

- **正文行高固定 1.8。**
- 标题行高 1.25–1.35（字大，行高要收紧，否则一个标题散成两块）。
- 代码块行高 1.7（等宽字体本身较窄，需要比拉丁正文松，但比中文正文紧）。
- 提示框、卡片描述这类小字号短文本，行高 1.7。

**不许**用一个行高值贯穿全站。中文正文和标题的行高必须分开设定。

## 二、段落与字距

- **中文正文不加字距。** 汉字本身已经是等宽方块，人为加字距会让词与词的边界消失，反而更难读。
- **段间距 = 一个行高**，不靠首行缩进分段。屏幕阅读用空行分段，不用两格缩进。
- **中文与西文之间加一个空格。** 中文字符与紧邻的拉丁字母、数字之间要有间隙，
  例如"把 title 取出来"、"返回 404"。
  - 这个空格由**排版规则**保证，不要求写内容的人手打。实现方式自选（自动插入或视觉间距），
    但**不许改变文字本身**——学员复制走的内容必须和源文一致。
  - 例外：紧贴标点时不加，例如"（middleware）"不写成"（ middleware ）"。

## 三、全角标点不悬挂，但要压缩

中文全角标点（，。、；：）自带左右各半个字宽的空白，连续出现时会形成难看的空洞。

- **禁止标点悬挂**（标点挂到版心之外）。中文竖排传统里的悬挂在横排屏幕上只会让右边缘参差不齐。
- **连续标点必须压缩**：句号后紧跟引号、书名号后紧跟逗号这类组合，中间的空白要收掉。
- **行首禁则**：这些字符不许出现在一行的开头 —— `，。、；：？！）』」》%‰℃` 以及后引号。
- **行尾禁则**：这些字符不许出现在一行的末尾 —— `（『「《` 以及前引号。
- 引号用 `“”` 和 `‘’`，不用 `「」`。破折号用两个全角 `——`，省略号用 `……`。

## 四、代码与中文混排的基线对齐

这是最容易出错的一条：中文字体和等宽拉丁字体的**基线位置和字面高度不同**，
行内代码直接塞进中文句子里，会明显地偏上或偏下，看起来像浮在句子上方。

- **行内代码必须与周围中文视觉居中对齐**，不是简单地共用基线。
  实现上通常需要对行内代码做一个小的垂直偏移，具体数值由所选字体对决定，
  **必须实测调出来，不许照抄别人的数字**。
- **行内代码的字号要比周围中文小一档**（约 0.9 倍）。等宽字体的字面通常比中文大，
  同号并排时代码会显得过重。
- **行内代码不许改变所在行的行高**。加了背景色和内边距之后，行距一旦被撑开，
  整段中文的节奏就毁了。
- **代码块内部不适用任何中文排版规则**：不加中西文间距、不压缩标点、不禁则。
  代码块里的每一个字符都必须和源文件逐字一致。

## 五、楷体标题字重

正文与标题都用楷体（霞鹜文楷一类的手写感字体）。这类字体的字重档位很少，
通常只有常规和粗体两档。

- **只用两档字重：常规（400）和粗体（700）。**
- **不许使用中间字重**（300 / 500 / 600 / 800）。字体文件里没有这些档，
  浏览器会用算法伪造，中文笔画会被均匀加粗，撇捺的粗细变化消失，字会"糊"。
  拉丁字母上不太看得出来，中文上一眼就能看出来。
- 模块编号、模块标题、屏标题、卡片标题一律用粗体；正文、说明文字用常规。
- **不许用倾斜。** 楷体没有真正的斜体，浏览器只会做几何倾斜，中文字形会被拉变形。
  需要强调时改用粗体或颜色。

## 六、其他

- **段落宽度**：正文每行 30–40 个汉字。超过 45 字读起来会丢行。
- **标点后不换字体**：中文句子里夹的英文单词换成拉丁字体，但紧跟其后的中文标点仍用中文字体。
- **数字**：正文里的数字用拉丁字体，和中文之间按第二条加间距。
- **文本可选中可复制。** 学员会去复制文件名、报错、命令。任何禁止选中的做法都不许出现。

## 验收标准

- [ ] 正文行高为 1.8，标题与正文的行高分开设定
- [ ] 中文正文没有额外字距
- [ ] 中文与拉丁字母/数字之间有视觉间距，且复制出来的文本不含多余空格
- [ ] 全角标点不悬挂；连续标点已压缩
- [ ] 行首不出现收尾类标点，行尾不出现起始类标点
- [ ] 行内代码与中文视觉居中，且没有撑开行高
- [ ] 全站只出现 400 与 700 两个字重，无倾斜文字
- [ ] 正文每行 30–40 个汉字
- [ ] 代码块内的字符与源文件逐字一致，未被任何排版规则改动
