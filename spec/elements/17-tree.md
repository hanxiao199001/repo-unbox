# 文件树 `kc-tree`

## 它是什么

带说明的目录树，替代一段"这个文件干什么、那个文件干什么"的文字罗列。

## 学员看到什么

缩进的树形结构。每一行：一个图标区分文件夹还是文件、一个等宽字体的名字、
一句中文说明。层级用左侧竖线和缩进表示。

## 学员能做什么

无交互。**树是全部展开的**，不做折叠——课程里的树很小，折叠只会多一次点击。

## 状态怎么变

无状态。

## 数据契约

| 名字 | 用在哪 | 必填 |
|---|---|---|
| `kc-tree` | 容器 | 是 |
| `kc-tree__dir` | 文件夹行 | 是 |
| `kc-tree__file` | 文件行 | 是 |
| `kc-tree__name` | 名字 | 是 |
| `data-kc-lang` | 名字 | 是 | 值恒为 `en` |
| `kc-tree__note` | 中文说明 | 是 |
| `kc-tree__children` | 子层容器 | 是 |

## 内容规则

- **总行数不超过 12**。真实项目的完整目录树对零基础学员是噪音，
  只列这门课会讲到的。
- 每一行都要有说明，**没有说明的行就不该出现在树里**。
- 说明用角色化的语言："大门口——启动程序，决定每种请求交给谁"，
  比"应用入口"有用得多。
- 路径和文件名英文原样。

## 失败与边界

- 某行缺说明 → 构建失败。
- 超过 12 行 → 构建时提示。
- 名字未标为英文 → 构建失败。

## 验收标准

- [ ] 层级关系一眼可辨
- [ ] 窄屏下说明换行到名字下方，不横向溢出
- [ ] 文件名可复制，与真实路径一致
