# 角色行 `kc-rolelist`

## 它是什么

一列"图标 + 名字 + 一句话"，用来介绍有哪几个角色。比卡片轻，比文字罗列清楚。

## 学员看到什么

纵向的若干行，每行左边一个彩色圆形图标，右边一个粗体名字和一句说明。

## 学员能做什么

无交互。

**它和概念卡片的区别**：卡片是并列的概念，横向铺开，每张有独立的描述段；
角色行是"名单"，纵向排列，一行一个，说明更短。介绍"系统里有谁"用角色行，
讲"有哪几种模式"用卡片。

## 状态怎么变

无状态。

## 数据契约

| 名字 | 用在哪 | 必填 |
|---|---|---|
| `kc-rolelist` | 容器 | 是 |
| `kc-rolelist__row` | 每一行 | 是 |
| `kc-rolelist__icon` | 圆形图标 | 是 |
| `data-kc-accent` | 每一行 | 是 | 取 1–5，决定图标颜色 |
| `kc-rolelist__name` | 名字 | 是 |
| `kc-rolelist__note` | 说明 | 是 |

**同一个角色在全课的颜色必须一致**，与组件群聊里的角色配色对齐。

## 内容规则

- **3–5 行**。
- 名字里如果是文件名，英文原样，并标为英文。
- 说明一句话，讲这个角色**负责什么**。
- 常用在模块一的开场，交代"这个项目由哪几部分组成"。

## 失败与边界

- 颜色取值超出范围 → 构建失败。
- 超过 6 行 → 构建时提示，建议改用文件树。

## 验收标准

- [ ] 同一角色在全课颜色一致
- [ ] 窄屏下图标与文字不重叠
