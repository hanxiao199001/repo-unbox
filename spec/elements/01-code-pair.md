# 代码对照 `kc-code-pair`

## 它是什么

左边一段源代码原文，右边逐行的中文解释。这是全课最重要的教学元素。

## 学员看到什么

一个左右分栏的块。

**左栏**：深色底的代码。顶上一行小字标着这段代码来自哪里，形式是「文件路径:起始行-结束行」。
代码带语法高亮。**代码不横向滚动**，长行自动折行。

**右栏**：浅色底，一列中文短句，每句对应左边一到两行代码。句与句之间有细分隔线。
顶上一行小字标着"中文逐行"。

窄屏时改为上下排布：代码在上，中文在下。

## 学员能做什么

- 选中并复制代码（必须支持，学员会拿去贴给 AI）。
- 悬停或点击中文里的术语，看术语气泡（见 `15-term.md`）。

没有其他交互。这是一个静态元素。

## 状态怎么变

无状态。

## 数据契约

| 名字 | 用在哪 | 必填 |
|---|---|---|
| `kc-code-pair` | 根节点 | 是 |
| `kc-code-pair__code` | 左栏 | 是 |
| `kc-code-pair__source` | 左栏顶部的来源标注 | 是 |
| `kc-code-pair__lines` | 右栏 | 是 |
| `kc-code-pair__line` | 右栏的每一条中文 | 是 |
| `data-kc-lang` | 代码区域 | 是 | 值恒为 `en`，让中文断行规则不作用于代码 |

来源标注的取值形式：`路径:起始行-结束行`，例如 `src/store.js:45-55`。路径相对于代码库根目录。

## 内容规则

**这是全项目最硬的一条约束：**

1. 代码必须是源文件里**连续的若干行**，**逐字复制**。不删、不简化、不改名、不加注释。
2. **允许整体去掉公共缩进；不许改动相对缩进。**
3. 空行是代码的一部分，保留。
4. **原作者写的注释是代码的一部分，不许删。** 那往往是最好的教学材料。
5. 需要展示不相邻的代码，就**开两个对照块**，各自连续，各自标注来源。**永远不拼接。**
6. 嫌某段太长？**换一段**，不要裁剪。
7. 右栏每条中文对应 1–2 行代码，讲"为什么"而不只是"是什么"。
8. 代码块整体不超过 12 行。

## 失败与边界

- 来源标注缺失或格式不对 → 构建失败。
- 代码在源文件里找不到逐字连续匹配 → 构建失败，并指出是哪个块、首行是什么。
- 来源标注的行号与实际找到的位置不符 → 构建失败。
- 右栏条数远多于代码行数（超过 1.5 倍）→ 提示，说明拆得过碎。

## 验收标准

- [ ] 任意宽度下代码都不出现横向滚动条
- [ ] 代码可选中、复制出来与源文件一致
- [ ] 每个块都有来源标注，且行号属实
- [ ] 窄屏下变为上下排布，中文在代码下方
- [ ] 代码区域内不生效任何中文排版规则
