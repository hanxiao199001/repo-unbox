# 编号步骤卡 `kc-steps`

## 它是什么

一串有先后顺序的步骤，纵向排列，每步一张卡片。

## 学员看到什么

纵向排列的卡片，每张左边一个圆形数字，右边一个小标题加一句说明。左侧有一条贯穿的强调边。

## 学员能做什么

无交互。

## 状态怎么变

无状态。

## 数据契约

| 名字 | 用在哪 | 必填 |
|---|---|---|
| `kc-steps` | 容器 | 是 |
| `kc-steps__item` | 每一步 | 是 |
| `kc-steps__num` | 圆形数字 | 是 |
| `kc-steps__title` / `kc-steps__body` | 标题与说明 | 是 |

编号**由内容作者写在标记里**，不由实现自动生成——课程里常需要从 1 以外的数字起步，
或者跳号强调。

## 内容规则

- **3–6 步**。
- 顺序必须是真实的时间或因果顺序。
- 标题是"发生了什么"，说明是"为什么"或"注意什么"。
- 步骤里出现的文件名、函数名英文原样。

## 失败与边界

- 编号缺失 → 构建失败。
- 只有 1–2 步 → 构建时提示，建议直接写成正文。

## 验收标准

- [ ] 编号与内容一致，无重复无跳漏（除非有意跳号）
- [ ] 窄屏下卡片不挤压变形
