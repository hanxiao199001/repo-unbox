# 输出题 `kc-output`

## 它是什么

要求学员**用自己的话写出来**的题。全课唯一一个逼学员产出内容的元素——
选择题只能证明他认得出答案，输出题才能证明他说得出来。

**每个模块结尾必须有一道。**

## 学员看到什么

一个方框，从上到下：

1. 一行小标签，写着这是哪一类输出题（三类见下）。
2. 题干，一句话。
3. 一个多行文本框，带一句降低压力的提示语（例如"不用写得漂亮，写得具体就行"）。
4. 文本框下方一行字数提示。
5. 一个按钮："我说完了，看对照清单"。**初始不可点。**
6. 一份对照清单，**初始不可见**。

## 学员能做什么

| 动作 | 结果 |
|---|---|
| 在文本框里打字 | 字数提示实时更新；写够字数后按钮变为可点 |
| 点按钮 | 对照清单出现；按钮变为不可点，不再消失 |
| 勾选清单里的项 | 下方出现"你勾了 N / M 项"，仅此而已 |
| 刷新页面 | 之前写的内容还在 |

**不评分、不判对错、不排名、不联网。** 判断权完全在学员自己手里。

## 状态怎么变

三个状态：

| 状态 | 进入条件 | 界面 |
|---|---|---|
| 未写够 | 初始，或写的字数 < 下限 | 提示"还差 N 字"；按钮不可点；清单隐藏 |
| 可揭晓 | 字数 ≥ 下限 | 提示"写了 N 字，可以看对照清单了"；按钮可点；清单仍隐藏 |
| 已揭晓 | 在"可揭晓"下点了按钮 | 清单可见；按钮永久不可点；勾选计数出现 |

- 从"可揭晓"退回"未写够"是允许的（学员删字）。
- **"已揭晓"是终态**，删字不会把清单收回去。
- 字数按去掉首尾空白后的字符数计，一个汉字算一个。

## 三类输出题

| 类别 | 问什么 |
|---|---|
| 复述路径 | "用你自己的话说一遍：点了那个按钮之后，数据经过了哪些文件？" |
| 给 AI 下指令 | "你要加一个功能。把你会对 AI 说的那句话原样写出来。" |
| 解释给朋友听 | "你朋友问'服务器到底是啥'，用不超过三句话讲给他听。" |

类别由数据属性声明，**标签文字由实现根据类别生成**，不由内容作者手写——
手写就会出现类别和文字对不上的情况。

## 数据契约

| 名字 | 用在哪 | 必填 | 取值 |
|---|---|---|---|
| `kc-output` | 根节点 | 是 | |
| 标识符 | 根节点 | 是 | 页面内唯一，草稿保存靠它区分 |
| `data-kc-kind` | 根节点 | 是 | `retell` / `instruct` / `explain` |
| `data-kc-min` | 根节点 | 是 | 整数，**不得小于 60**，建议 60–120 |
| `kc-output__label` | 类别标签 | 是 | 内容留空，由实现填写 |
| `kc-output__prompt` | 题干 | 是 | |
| `kc-output__input` | 文本框 | 是 | |
| `kc-output__meter` | 字数提示 | 是 | 内容由实现填写 |
| `kc-output__reveal` | 按钮 | 是 | |
| `kc-output__checklist` | 对照清单容器 | 是 | 初始隐藏 |
| `kc-output__item` | 清单每一项 | 是 | 每项含一个勾选框和一段说明 |
| `kc-output__tally` | 勾选计数 | 否 | 没有则由实现创建 |

## 内容规则

- 清单 **3–4 条**，不多不少。
- 每条点名一个**具体**的东西：一个文件名、一个函数名、一个该学会的术语、一个顺序。
- **至少一条要用英文标注一个东西**：
  - 复述路径 / 给 AI 下指令 → 文件名或函数名
  - 解释给朋友听 → **这个概念的英文原词**。这类题本来就要求学员别用术语，
    逼他写文件名是和题意打架；让他说出英文原词反而服务于语言目标。
- 四条都是"说清楚了顺序""讲明白了原理"这种空话 → 不合格，学员无从自查。
- 输出题放在模块**最后**，选择题之后。

## 草稿保存

- 学员打的字保存在**本机浏览器**里，键用元素标识符。
- **不许上传，不许联网。**
- 保存不可用时（隐私模式、存储被禁）静默降级：不保存，其余功能照常。
  **不许因此报错或阻断。**

## 失败与边界

- 缺类别、类别不在三个值里 → 构建失败。
- 字数下限缺失或小于 60 → 构建失败。下限太低学员会打"就是那样"然后跳过，这个元素就废了。
- 缺标识符 → 构建失败（草稿会互相覆盖）。
- 清单不是 3–4 条 → 构建失败。
- 清单里没有任何英文标注 → 构建失败。
- 脚本未运行 → 文本框仍可输入，清单**应当直接可见**，而不是永远打不开。

## 验收标准

- [ ] 未写够字数时按钮点不动
- [ ] 写够后按钮可点，提示文字改变
- [ ] 点开清单后再删字，清单不会收回
- [ ] 勾选后出现计数，且不出现任何"对/错""得分"字样
- [ ] 刷新页面，之前写的字还在
- [ ] 隐私模式下不报错，功能照常
- [ ] 标签文字与声明的类别一致
- [ ] 键盘可以走完全流程
