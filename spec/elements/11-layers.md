# 分层切换 `kc-layers`

## 它是什么

同一个东西的几个层次，用标签页切换。适合讲"一层层叠上去"的递进关系。

## 学员看到什么

一排标签（例如"骨架"、"加上样式"、"加上交互"），下面一个展示区，再下面一句说明当前这一层是什么。
初始显示第一层。

## 学员能做什么

| 动作 | 结果 |
|---|---|
| 点一个标签 | 展示区换成这一层；该标签变为选中；说明文字随之更换 |
| 键盘左右方向键 | 在标签之间移动并切换 |

## 状态怎么变

一个当前层，初始为第一层。切换是排他的：任何时刻只有一层可见、一个标签选中。

## 数据契约

| 名字 | 用在哪 | 必填 |
|---|---|---|
| `kc-layers` | 根节点 | 是 |
| `kc-layers__tab` | 每个标签 | 是 |
| `data-kc-layer` | 每个标签 | 是 | 指向对应层 |
| `kc-layers__panel` | 每一层 | 是 |
| 层标识符 | 每一层 | 是 | **整页唯一**，中间要带模块特有的部分 |
| `kc-layers__note` | 说明文字 | 是 |
| `data-kc-note` | 每个标签 | 是 | 切到这一层时显示的说明 |
| `kc-is-current` | 选中的标签 | — |

标签与层必须**一一对应，双向可查**。

## 内容规则

- **2–4 层**。超过 4 层就不是递进，是列表了。
- 层的顺序必须是真正的递进关系，不是并列关系。并列关系用卡片。
- 说明一句话，讲"这一层加上了什么、解决了什么"。

## 失败与边界

- 标签指向不存在的层 → 构建失败。
- 有层没有任何标签指向 → 构建失败。
- 层标识符重复 → 构建失败。
- 脚本未运行 → **所有层应当依次全部可见**（退化成一个纵向列表），而不是只剩第一层。

## 验收标准

- [ ] 任意时刻只有一层可见
- [ ] 同一页面两组分层互不干扰
- [ ] 键盘左右键能切换
- [ ] 脚本禁用时所有层都能看到
