# 图示 `kc-figure`

## 它是什么

一张图加一行说明。截图、示意图、界面照片都走这一个元素。

## 学员看到什么

一张图，宽度不超过版心，圆角、暖色细边、轻微阴影。图下面一行小字，说这张图是什么。

窄屏时图跟着缩，不横向溢出。

## 学员能做什么

无交互。

## 状态怎么变

无状态。

## 数据契约

| 名字 | 用在哪 | 必填 | 说明 |
|---|---|---|---|
| `kc-figure` | 根节点，用 `<figure>` | 是 | |
| `kc-figure__image` | `<img>` | 是 | |
| `src` | 同上 | 是 | **必须是课程目录内的相对路径**，不许是外网地址 |
| `alt` | 同上 | 是 | 一句话描述图里有什么，给看不见图的人用 |
| `kc-figure__caption` | `<figcaption>` | 是 | 一行说明 |

## 内容规则

- **`alt` 和说明不是一回事。** `alt` 描述图里**有什么**（"左侧是发射表单，右侧是三条留言"），
  说明讲这张图**为什么在这儿**（"这是它在本机真实跑起来之后截的"）。两句都要写。
- 说明一行，不超过一句话。要写两句以上，说明该写进正文而不是图注。
- 截图必须是**真的跑出来截的**。跑不起来就不要放图，改用文字描述界面。
  **绝不许编造截图，也绝不许假装自己跑过。**

## 失败与边界

- `<img>` 带了内联 `style` → 构建失败。样式全在 `styles.css` 里，
  内联样式会让一门课里的图各长各的样。
- `<img>` 不在 `kc-figure` 里、缺 `alt`、或缺 `kc-figure__caption` → 构建失败。
- `src` 指向外网 → 已有的"零外部请求"检查会卡住。
- 图片文件不存在 → 已有的"local assets exist"检查会卡住。
- 脚本未运行 → 图和说明照常显示。

## 验收标准

- [ ] 图不超过版心宽度，窄屏下不横向溢出
- [ ] 每张图都有 `alt`，且不是文件名
- [ ] 每张图都有一行说明
- [ ] 全课没有任何 `<img>` 带内联 `style`
