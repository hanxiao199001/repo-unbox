# 这里没看懂 `kc-feedback`

## 它是什么

每一屏右上角一个小按钮。学员看不懂这一屏时点一下，页面把"哪个模块、哪一屏、什么时候"
记在他自己的浏览器里，可以再补一句话。课末一个按钮把全部记录导出成一个 JSON 文件。

**不联网、不上报、不判分。** 这些数据只在学员自己的机器上，只有他自己能导出。
他愿意把文件发给谁，是他的事。

## 学员看到什么

每一屏的右上角有一个小按钮，安静地待着，不抢内容的注意力。点过的那一屏，按钮变成
"已标记"的样子，并且这个状态在刷新之后还在。

课末有一块，写着"你一共标了 N 处没看懂"，下面两个按钮："导出反馈"和"清空"。
一处都没标时，这一块也在，只是数字是 0。

## 学员能做什么

| 动作 | 结果 |
|---|---|
| 点某一屏的按钮 | **立刻记下一条**（模块、屏、时间）；按钮变为已标记；旁边展开一个输入框 |
| 在输入框里写一句话 | 这句话补进刚才那条记录；不写也没关系，那条记录照样成立 |
| 再点一次同一个按钮 | 撤销这一条，按钮回到未标记 |
| 点"导出反馈" | 浏览器下载一个 JSON 文件，内容是全部记录 |
| 点"清空" | 全部记录删除，所有按钮回到未标记 |
| 刷新页面 | 标记过的屏还是标记状态，写过的话还在 |

**撤销必须有。** 点错一下就永久留一条脏数据，学员下次就不敢点了。

## 状态怎么变

每个按钮两个状态，外加一个可选的输入框：

| 状态 | 进入条件 | 界面 |
|---|---|---|
| 未标记 | 初始，或在已标记时再点一次 | 按钮是安静的轮廓样子；输入框收起 |
| 已标记 | 点了按钮 | 按钮变实心并显示已标记；输入框展开，可以写一句话 |

记录写进本机存储的时刻是**点下按钮那一刻**，不是写完话那一刻——
学员写到一半关掉页面，这一条也该在。

## 数据契约

| 名字 | 用在哪 | 必填 | 说明 |
|---|---|---|---|
| `kc-feedback` | 每一屏的按钮 | 是 | 由构建脚本注入，写内容的人不用管 |
| `kc-feedback__panel` | 按钮旁边的输入区 | 是 | 由实现创建 |
| `kc-feedback__note` | 那一句话的输入框 | 是 | 由实现创建 |
| `kc-is-marked` | 已标记的按钮 | — | |
| `kc-feedback-export` | 课末那一块的根节点 | 是 | 在 `_footer.html` 里，一页一个 |
| `kc-feedback-export__count` | "你一共标了 N 处" | 是 | 内容由实现填 |
| `kc-feedback-export__button` | 导出按钮 | 是 | |
| `kc-feedback-export__clear` | 清空按钮 | 是 | |
| `kc-feedback-export__fallback` | 下载被拦时的兜底文本框 | 是 | 平时不可见 |

一条记录含：模块标识符、模块编号、模块标题、这一屏在模块里的序号、屏标题、
那一句话（可以是空字符串）、时间戳（ISO）。

## 内容规则

写内容的人**什么都不用写**。按钮由 `scripts/build.mjs` 注入到每一个 `kc-screen`，
课末那一块在 `_footer.html` 里。

## 失败与边界

- 有 `kc-screen` 没有反馈按钮 → 构建失败。
- 缺课末那一块 → 构建失败。
- 本机存储不可用（隐私模式、存储被禁）→ **静默降级**：按钮还能点、还能标记，
  只是刷新之后不保留，导出仍然可用（导出的是这一次会话里的记录）。不许报错、不许阻断。
- 浏览器拦住下载（有些环境不允许页面发起下载）→ 把 JSON 显示在兜底文本框里，
  让学员自己复制。**不许什么都不发生。**
- 脚本未运行 → 按钮照常显示但点不动，课末那一块也照常显示。正文完全不受影响。

## 验收标准

- [ ] 每一屏都有按钮，且在右上角
- [ ] 点一下立刻记下一条，刷新之后还在
- [ ] 再点一次能撤销
- [ ] 那一句话是可选的，不写也能成立
- [ ] 导出的 JSON 里有模块号、屏标题、时间戳
- [ ] 全程不发出任何网络请求
- [ ] 隐私模式下不报错，按钮照常可点
- [ ] 键盘能聚焦按钮并触发
