# 页面骨架

## 它是什么

一门课是**一个页面**。学员从上往下滚，走完全部内容。没有路由、没有分页、没有下一页按钮。

## 层级

三层，从外到内：

```
课程 (kc-course)
  └── 模块 (kc-module)          一门课 4–6 个
        └── 屏 (kc-screen)      一个模块 3–6 个
              └── 元素          代码对照、测验、输出题、图示……
```

- **课程**：整个页面的内容容器。一门课一个。
- **模块**：一个大主题。占据至少一整屏高度。学员滚动时，模块之间有明显的分界感。
- **屏**：模块内部的一节，讲**一个**概念。屏不强制占满视口高度，长度随内容。

## 学员看到什么

页面顶部固定着导航条（见 `navigation.md`）。往下是模块，一个接一个。

每个模块开头有一个**模块头**，包含三样东西，从上到下：

1. **编号** —— 两位数（01、02……）。视觉上很大、很淡，是装饰性的定位标记，不是要读的内容。
2. **标题** —— 这个模块讲什么。
3. **副标题** —— 一句话说明这个模块要带学员做成什么。

模块头之后是若干屏。每屏可以有一个**屏标题**（比模块标题小一级），也可以没有。

## 视觉节奏

- **相邻模块的背景色必须不同**，在两种色调之间交替。这是学员判断"我进入下一个模块了"的
  唯一视觉信号，不能省。
- 模块之间需要足够的留白，让人喘得过气。
- **每屏至少一半的面积是非文字的**：图示、代码、卡片、动画、徽章都算。
  连续三段以上纯文字而没有任何视觉元素，视为不合格。

## 滚动行为

- 滚动到模块边界时有**轻微**的吸附感，帮助学员停在模块开头。
- **吸附必须是弱的**：内容比视口高的模块，学员必须能停在模块中间，
  不许被强行推到下一个模块。这是硬要求——强吸附会把人困在长模块里出不来。

## 入场动画

元素滚动进入视口时淡入并轻微上移一次，只播一次，不循环。

**必须满足**：如果动画脚本没有运行（脚本出错、被禁用），
所有内容必须**照常可见**。绝不允许出现"脚本挂了导致整页空白"。

## 数据契约

| 名字 | 用在哪 | 必填 | 说明 |
|---|---|---|---|
| `kc-course` | 内容容器 | 是 | 一个页面一个 |
| `kc-module` | 每个模块的根节点 | 是 | |
| `kc-module__number` | 模块编号 | 是 | |
| `kc-module__title` | 模块标题 | 是 | |
| `kc-module__subtitle` | 模块副标题 | 是 | |
| `kc-screen` | 每一屏 | 是 | |
| `kc-screen__title` | 屏标题 | 否 | |
| 模块标识符 | 每个模块 | 是 | 页面内唯一，导航圆点靠它定位 |
| `data-kc-metaphor` | 每个模块 | 是 | 这个模块用的比喻，一门课内不许重复 |
| `data-kc-tone` | 每个模块 | 是 | 取 `a` 或 `b`，相邻模块必须不同，决定背景色调 |

## 内容规则

- 一门课 **4–6 个模块**。只有当代码库真的有那么多值得讲的概念时才做到 7–8 个。
- 一个模块 **3–6 屏**。
- 每个模块的中文正文**不少于 800 字**（不含代码块内的文字）。
- 每个模块至少有一处代码对照、一道测验、一道输出题。
- 每个模块的比喻必须写进 `data-kc-metaphor`，且一门课内不重复。

## 失败与边界

- 模块缺少标识符：导航圆点无法定位到它 —— **构建必须失败**，不许悄悄跳过。
- 相邻模块 `data-kc-tone` 相同：视觉分界消失 —— **构建必须失败**。
- 模块少于 3 屏：允许，但应在构建输出里提示。

## 验收标准

- [ ] 断网打开，页面完整，字体正确，没有任何请求发出
- [ ] 禁用 JavaScript 打开，所有文字和代码依然可读
- [ ] 相邻模块背景色不同，肉眼可辨
- [ ] 一个高于视口两倍的模块，能停在中间，不被强行吸附走
- [ ] 每个模块都有编号、标题、副标题
- [ ] 每个模块声明了比喻，且全课不重复
