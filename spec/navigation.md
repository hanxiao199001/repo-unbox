# 导航与进度条

## 它是什么

固定在页面顶部的一条，让学员随时知道"我在第几个模块、还剩多少"，并能跳到任意模块。

## 学员看到什么

从上到下两层：

1. **进度条** —— 贴着页面最顶端的一条细线，宽度代表整页已滚动的比例。
   滚到底时占满整个宽度。
2. **导航行** —— 左边是课程标题，右边是一排圆点，一个模块一个。

### 圆点的三种外观

| 状态 | 什么时候 | 外观要求 |
|---|---|---|
| 未到达 | 学员还没滚到这个模块 | 最弱，只是一个轮廓 |
| 已读过 | 学员滚过去了，但当前不在这里 | 中等强度，明显区别于未到达 |
| 当前 | 当前视口中心落在这个模块里 | 最强，且带一圈外扩的光晕 |

**三种状态必须靠形状或明暗区分，不能只靠颜色**——色觉障碍的学员要能分辨。

鼠标悬停在圆点上时，显示该模块的标题。

## 学员能做什么

| 动作 | 结果 |
|---|---|
| 点圆点 | 平滑滚动到对应模块的开头 |
| 键盘聚焦到圆点后按回车或空格 | 同上 |
| 按向下方向键 / PageDown | 跳到下一个模块开头 |
| 按向上方向键 / PageUp | 跳到上一个模块开头 |
| 按 Home / End | 跳到第一个 / 最后一个模块 |
| 正常滚动 | 进度条和圆点跟着变，不需要点任何东西 |

**键盘跳转在输入框获得焦点时必须失效**——学员正在输出题里打字时按方向键，
应该是在文本里移动光标，不是跳模块。这是必须处理的边界。

## 状态怎么变

单一输入是**页面滚动位置**，输出两样：

1. **进度条宽度** = 已滚动距离 ÷ 可滚动总距离。
2. **当前模块** = 视口垂直中心落在哪个模块的范围内。
   - 视口中心在某模块内 → 该圆点为"当前"
   - 视口底部已越过某模块顶部，但中心不在其中 → 该圆点为"已读过"
   - 其余 → "未到达"

滚动是高频事件，状态更新必须节流到每帧一次，不允许每次滚动事件都重算。

## 数据契约

| 名字 | 用在哪 | 必填 | 说明 |
|---|---|---|---|
| `kc-nav` | 导航条根节点 | 是 | |
| `kc-nav__progress` | 进度条 | 是 | 需要向辅助技术暴露当前百分比 |
| `kc-nav__title` | 课程标题 | 是 | |
| `kc-nav__dots` | 圆点容器 | 是 | |
| `kc-nav__dot` | 单个圆点 | 是 | 每个模块一个，顺序与模块一致 |
| `data-kc-target` | 圆点 | 是 | 值是目标模块的标识符 |
| `data-kc-label` | 圆点 | 是 | 悬停时显示的模块标题 |
| `kc-is-current` | 圆点 | — | 当前模块 |
| `kc-is-visited` | 圆点 | — | 已读过 |

圆点必须是**可聚焦的按钮**，并向辅助技术说明它是一组标签页中的一项、
以及"第 N 个模块：标题"。

## 内容规则

- 圆点数量必须等于模块数量，顺序一致。
- 每个圆点的目标必须对应一个真实存在的模块标识符；反过来，每个模块都必须有圆点指向它。
  **双向都要检查**。

## 失败与边界

- 圆点指向不存在的模块 → 构建失败。
- 有模块没有任何圆点指向 → 构建失败。
- 页面短到不可滚动 → 进度条保持满格，不报错。
- 脚本未运行 → 导航条仍然显示，圆点不响应点击，但页面内容照常可读可滚。

## 验收标准

- [ ] 圆点数量与模块数量一致，双向对应
- [ ] 三种圆点状态在灰度截图里仍可区分
- [ ] 键盘能聚焦到每个圆点并触发跳转
- [ ] 在输出题文本框里按方向键，光标在文字里移动，页面不跳模块
- [ ] 滚到底时进度条满格
- [ ] 快速滚动时不掉帧、不闪烁
