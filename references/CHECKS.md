# 校验清单

> **什么时候读：** 写模块之前扫一眼，构建失败之后按编号查。
>
> **不要去读 `scripts/validate.mjs`。** 那是这份清单的实现，四百多行，读它只会把上下文塞满，
> 而且读完你得到的还是这一页的内容。构建失败时报错里会打出编号，回到这里对编号就行。

一共 55 项。带 ⚠ 的是警告，不会让构建失败。

## 页面骨架

| 编号 | 查什么 |
|---|---|
| C01 | 数据流演示的 `data-kc-steps` 必须是能解析的 JSON。说明文字里有英文单引号就会断在这儿 |
| C02 | 整页的 `id` 不许重复 |
| C03 | 每个模块都要有 `id` |
| C04 | 导航圆点和模块双向对应：每个圆点指向一个真实模块，每个模块都有圆点指向它 |
| C05 | 相邻模块的 `data-kc-tone` 必须在 `a`/`b` 之间交替，取值只能是这两个 |
| C06 | `index.html` 里不许残留 `{{占位符}}` |
| C10 | 页面引用的本地文件必须真的存在 |

## 离线与字体
