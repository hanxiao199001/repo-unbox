进站要过几道关

请求到达柜台之前，先被几个人依次摸了一遍。

中间那一层

上一模块留了一个尾巴：那一行里，validateCreate 排在真正干活的函数前面。它是什么？

它是中间件。

这就像坐地铁进站：安检机 → 闸机 → 站台。每一关都能把你拦下来，也都能放你过去。放过去了，你就到下一关；被拦下来，你根本走不到站台。

请求也是一样。它到达待办柜台之前，已经被好几个人依次摸过一遍了。

→
2记一行日志
→

→
4柜台真正干活

第二关：每一次请求都被记了一笔

这段是项目自己写的一个中间件。它谁也不拦，只是把每次请求记下来。

src/server.js:16-24

// Log every request: method, path, and how long it took
app.use((req, res, next) => {
  const startedAt = Date.now();
  res.on('finish', () => {
    const ms = Date.now() - startedAt;
    console.log(`${req.method} ${req.originalUrl} -> ${res.statusCode} (${ms}ms)`);
  });
  next();
});

原作者的注释：记下每个请求的动作、路径和耗时。

app.use 就是“往关卡链上加一道”。这道关对所有请求生效。

先记一下现在几点。

给“回复发完了”这件事挂一个监听。finish 那一刻才知道这次总共花了多久。

用结束时间减开始时间，得到毫秒数。

打印一行。你在终端里看到的 POST /api/todos -> 201 (3ms) 就是这一行印的。

监听挂完了。

这一行不能少。next() 就是“放行，交给下一关”。忘了写，请求会一直卡在这里，页面转圈转到超时。

这道关到此结束。

⚠

最常见的一个坑

中间件里忘了调 next()，请求既不报错也不返回，页面就一直转圈。这类问题不会打印任何东西，因为程序并没有“出错”，它只是在等一个永远不来的信号。

第三关：真正会拦人的那一道

上一道关谁都放行。这一道不一样——标题不合格，它直接把你挡在门外。

src/middleware/validate.js:12-23

// Guards POST /api/todos — a new todo must have a usable title.
export function validateCreate(req, res, next) {
  const title = cleanTitle(req.body?.title);
  if (title === null) {
    return next(new HttpError(400, 'title is required', {
      field: 'title',
      rule: `non-empty string, at most ${MAX_TITLE_LENGTH} characters`,
    }));
  }
  req.body.title = title;
  next();
}

原作者的注释：守住新建这条路，新待办必须有一个能用的标题。

函数名 validate 是“校验”，Create 是“新建”，合起来就是“新建时的校验”。

把标题拿去洗一遍：去掉首尾空格，太长或者洗完是空的就返回 null。

洗出来是 null，说明这个标题不能用。

拦下来，报 400。400 的意思是“你发来的东西不对”，不是“服务器坏了”。

顺便告诉对方是哪个字段出的问题。

以及这个字段的规矩是什么。这两行让报错变得可以照着改，而不只是“不行”。

拦截结束，注意开头那个 return——没有它，代码会继续往下跑。

这一段的括号收尾。

这一行容易被忽略：把洗干净的标题写回请求里。后面的柜台拿到的就是去过空格的版本。

放行，交给下一关。

输入校验要放在后端（input validation）

页面上那个输入框也写了 required，但那只是提醒，任何人打开开发者工具就能绕过去。真正拦得住的检查必须在服务器这一侧。这条原理跳出这个项目也成立。

有人在日志中间件里把最后那行 next() 删掉了。会发生什么？

你要给待办加一个“最长 50 个字”的限制，这个检查放在哪儿？

你要让待办支持“紧急”标记。把你会对 AI 说的那句话原样写出来——要具体到文件和关卡。

  • 点名了 validate.js，要求在那里校验新字段，而不是只说“加个字段”
  • 提到了 store.js 里创建待办的那个地方也要跟着改
  • 说清楚了不合格时应该回 400，而不是让它悄悄通过
