怎么把机器人挡在外面

三道完全不同的防线，各挡一种人。

为什么留言板一定会被刷

任何人不用登录就能发的地方，一定会被自动脚本盯上。这个项目布了三道防线，而且三道挡的是完全不同的三种情况。

就像接收站上串起来的三个滤波器：一个滤掉发得太频繁的，一个滤掉根本不是人的，一个滤掉内容本身是垃圾的。

◔

限流

按 IP 数次数：两条之间至少隔 10 秒，一小时最多 10 条。挡的是“发得太快的人”。

◕

蜜罐

一个人类看不见的输入框。填了就直接判垃圾。挡的是“照着表单硬填的脚本”。

◑

算术题

服务器出一道加法，配一张五分钟过期的票据。挡的是“没有真正打开过页面的请求”。

第一道：数次数

server.js:87-92

  if (entry.lastPostAt && now - entry.lastPostAt < minGapMs) {
    return jsonError(res, 429, 'Rate limit: wait at least 10 seconds between transmissions.');
  }
  if (entry.recent.length >= maxPostsPerWindow) {
    return jsonError(res, 429, 'Rate limit: maximum 10 transmissions per hour.');
  }

如果这个 IP 上一次发言的时间还在，而且离现在不到 10 秒——

直接回 429。注意它给的是人话：“两次之间至少等 10 秒”，而不是干巴巴一句“被拒绝”。

第一道判断结束。

如果这一小时之内已经发过 10 条——

同样回 429，但换一句更准确的话。两种情况用同一个状态码，却给不同的解释，用户才知道该等 10 秒还是该等一小时。

第二道判断结束。

⚠

这份计数只在内存里

限流记录存在一个 Map 里，服务一重启就全没了。好处是不用存任何人的 IP，坏处是重启一次所有人的额度都清零。项目自己在 README 里写明了这个取舍。

第二、三道：内容和身份

server.js:168-179

  if (website) {
    return jsonError(res, 400, 'Spam detected.');
  }
  if (!message) {
    return jsonError(res, 400, 'Message is required.');
  }
  if (!hasMeaningfulContent(message)) {
    return jsonError(res, 400, 'Message must include at least one letter or number.');
  }
  if (isRepeatedSpam(message)) {
    return jsonError(res, 400, 'Message looks like repeated-character spam.');
  }

蜜罐字段有内容，直接判定为垃圾。人看不见那个框，填了的一定不是人。

回 400 并说明原因。

第一道判断结束。

留言是空的。

回 400，告诉他留言是必填的。

第二道结束。

留言里连一个字母或数字都没有——比如整条只有标点和空格。

回 400。这一条挡的是“看起来不空、其实什么都没说”的内容。

第三道结束。

留言是一长串重复字符，比如八个以上一样的字挨在一起。

回 400。四道判断从上往下依次执行，任何一道命中就直接返回，后面的根本不跑。

最后一道结束。

server.js:53-60

function makeHumanCheck() {
  const a = randomInt(2, 12);
  const b = randomInt(1, 12);
  const token = `${Date.now().toString(36)}-${Math.random().toString(36).slice(2, 12)}`;
  const answer = String(a + b);
  humanChecks.set(token, { answer, expiresAt: Date.now() + humanCheckTTL });
  return { token, question: `${a} + ${b} = ?` };
}

出一道人机验证题。

随机取一个 2 到 12 的数。

再取一个 1 到 12 的数。

编一张票据：当前时间加一段随机字符。

答案留在服务器这边，不发给浏览器。这一点是关键——发出去就等于把答案告诉了机器人。

把票据和答案记下来，同时记一个五分钟后的过期时间。

只把票据和题面发出去。

函数结束。
